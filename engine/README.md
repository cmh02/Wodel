# Wodle - Engine Module

The Wodle Engine Module is broken up into a few subcomponents for pipelinining.

## Data Engine

The data engine is in charge of all pre-processing of any input data to the Wodel system. It provides a simple pipeline for standardizing data and an interface for using data once processed.

## Model Engine

The model engine is in charge of training models, evaluating them, and generating model performance reports.
